## 1. mitmproxy 소개
**mitmproxy**는 네트워크 흐름을 콘솔(CLI), 웹(Web UI), 또는 파이썬 스크립트 인터페이스를 통해 제어할 수 있는 강력한 중간자(Man-in-the-Middle) 프록시 도구입니다.

*   `mitmproxy`: 터미널 기반의 대화형 CLI 도구.
*   `mitmweb`: 브라우저 기반의 깔끔한 GUI 웹 인터페이스 도구 (**초보자 및 시각적 분석에 적극 추천 ⭐**).
*   `mitmdump`: `tcpdump`처럼 터미널에 로그를 저장하거나 파이썬 스크립트(Addon)를 로드하여 자동화 처리를 수행하는 도구.

## 2. 설치 및 준비 (macOS)

macOS 환경에서는 패키지 관리자인 **Homebrew**를 이용해 설치하는 것이 가장 간편하고 깔끔합니다.

### Homebrew를 통한 설치
터미널을 열고 아래 명령어를 입력합니다:
```bash
brew install mitmproxy
```

### 설치 확인
설치가 완료되었는지 버전을 확인해 봅니다:
```bash
mitmproxy --version
```

## 3. 모바일 기기 연동 설정

분석하려는 스마트폰(iOS/Android)과 PC가 **반드시 동일한 Wi-Fi(공유기) 네트워크**에 연결되어 있어야 합니다.

### 1단계: 분석용 PC의 로컬 IP 주소 확인
macOS 터미널에서 다음 명령어를 실행하여 PC의 사설 IP 주소(예: `192.168.x.x` 또는 `172.x.x.x`)를 확인합니다.
```bash
# Wi-Fi 카드 인터페이스(보통 en0)의 IP 확인
ipconfig getifaddr en0
```
*(예를 들어, PC의 IP 주소가 `192.168.1.15`라고 가정하겠습니다.)*

### 2단계: 스마트폰의 프록시 설정 변경
스마트폰의 Wi-Fi 설정으로 이동하여 PC의 프록시 서버를 경유하도록 설정합니다.

#### 📱 iOS (아이폰)
1. **설정** > **Wi-Fi**로 이동합니다.
2. 현재 연결된 Wi-Fi 이름 옆의 **(i) 아이콘**을 누릅니다.
3. 맨 아래로 스크롤하여 **프록시 구성**을 선택하고 **수동**으로 변경합니다.
4. **서버**: PC의 로컬 IP 주소 (`192.168.1.15`)를 입력합니다.
5. **포트**: `8080` (mitmproxy의 기본 포트)을 입력하고 저장합니다.

#### 🤖 Android (안드로이드)
1. **설정** > **연결** > **Wi-Fi**로 이동합니다.
2. 현재 연결된 Wi-Fi의 **톱니바퀴(설정) 아이콘**을 누릅니다.
3. **더보기/고급** 설정을 누른 후 **프록시**를 **수동**으로 변경합니다.
4. **프록시 호스트 이름**: PC의 로컬 IP 주소 (`192.168.1.15`)를 입력합니다.
5. **프록시 포트**: `8080`을 입력하고 저장합니다.

## 4. HTTPS 복호화를 위한 CA 인증서 설치

프록시가 설정된 상태에서 인터넷을 연결하면, 스마트폰 브라우저에 "연결이 비공개 상태가 아닙니다"라는 경고가 뜹니다. 암호화된 HTTPS 데이터를 mitmproxy가 복호화할 수 있도록 신뢰할 수 있는 인증서를 등록해야 합니다.

### 1단계: PC에서 프록시 서버 시작
PC 터미널에서 아래 명령을 실행해 프록시 서버를 먼저 켜 둡니다:
```bash
mitmweb
```
*(기본적으로 포트 8080에서 프록시 서버가 가동되며, 브라우저에 `http://127.0.0.1:8081` 웹 모니터링 페이지가 열립니다.)*

### 2단계: 스마트폰에서 인증서 다운로드
1. 스마트폰에서 웹 브라우저(Safari, Chrome 등)를 엽니다.
2. 주소창에 다음 주소를 입력해 접속합니다:
   ```text
   http://mitm.it
   ```
3. 페이지가 로드되면 사용하는 OS(iOS 또는 Android)용 **Show Contents**를 누른 뒤 **인증서 다운로드(Download Certification)** 버튼을 눌러 프로파일/인증서를 다운로드합니다.
   * *접속이 안 된다면 스마트폰의 Wi-Fi 프록시 설정이 PC IP 및 8080 포트로 올바르게 설정되어 있는지 다시 확인하세요.*

### 3단계: 스마트폰에서 인증서 설치 및 신뢰 승인

#### 📱 iOS (아이폰)
1. **설정** > **프로파일이 다운로드됨**으로 이동하여 **설치**를 누릅니다.
2. **설정** > **일반** > **정보** > 맨 아래 **인증서 신뢰 설정**으로 이동합니다.
3. **mitmproxy** 루트 인증서 우측의 스위치를 활성화(초록색)하여 **전체 신뢰를 활성화**합니다. (⚠️ 이 단계를 누락하면 HTTPS 통신이 불가능합니다.)

#### 🤖 Android (안드로이드)
1. **설정** > **보안 및 개인정보 보호** > **보안 추가 설정** > **암호화 및 자격증명** > **인증서 설치** > **CA 인증서**로 이동합니다.
2. 경고 창이 뜨면 **무조건 설치**를 선택합니다.
3. 다운로드한 `mitmproxy-ca-cert.pem` 파일을 찾아 선택하여 설치를 완료합니다.

## 5. mitmweb을 이용한 시각적 트래픽 분석

모든 설정이 완료되었다면 이제 스마트폰에서 분석하려는 앱을 켜고 트래픽을 관찰할 수 있습니다.

1. PC 브라우저에 열려 있는 **mitmweb 대시보드 (`http://127.0.0.1:8081`)**를 띄워둡니다.
2. 스마트폰에서 분석하고자 하는 모바일 앱을 실행하여 로그인하거나 페이지를 새로고침 해봅니다.
3. 웹 대시보드 화면에 실시간으로 앱이 보내는 API 요청(`GET`, `POST` 등)이 리스트업되는 것을 관찰합니다.

### 유용한 대시보드 기능
*   **필터 기능 (Filter)**: 대시보드 상단 Search 창에 `~u school` 또는 `~m post`를 입력해 특정 도메인 주소나 POST 방식만 걸러서 볼 수 있습니다.
*   **상세 분석 (Detail View)**: 특정 요청을 클릭하면 우측 탭에서 다음 내용을 정밀 분석할 수 있습니다.
    *   **Request**: 헤더 정보, Query 파라미터, POST Body JSON 데이터
    *   **Response**: 서버가 돌려준 JSON 결과물, 응답 코드(200 OK 등)
    *   **Detail**: 연결 소요 시간, SSL 버전 정보

## 6. 파이썬 스크립트를 활용한 패킷 인터셉트 및 위변조 실습

**mitmproxy의 진정한 강점**은 파이썬 코드를 이용해 패킷의 요청과 응답을 프로그램 수준에서 조작할 수 있다는 점입니다.

이를 통해 실제 학교 서버에 조작된 값을 전송하지 않고, **서버가 보낸 응답(Response) 데이터를 PC에서 변조하여 내 스마트폰 앱 화면에 어떻게 나타나는지 확인하는 안전한 시뮬레이션 실습**이 가능합니다.

### 실습 예제: 서버가 내려준 특정 값 조작하기
스마트폰 화면에 표시되는 텍스트나 데이터를 프록시 서버 단에서 중간 변조하는 파이썬 코드를 작성해 봅니다.

#### 1단계: 애드온 스크립트 작성 (`docs/mitm_addon.py`)
아래 파이썬 코드는 서버가 내려주는 JSON 데이터 중 특정 문구나 공지사항을 조작하는 간단한 애드온 프로그램입니다.

```python
import json
from mitmproxy import http

def response(flow: http.HTTPFlow) -> None:
    # 1. 분석하고자 하는 타겟 도메인/API 주소가 포함되어 있는지 확인
    # (실습 시 학교 API 도메인 키워드로 교체하세요)
    if "example.com" in flow.request.pretty_url or "school" in flow.request.pretty_url:
        
        # 2. 서버가 200 OK 응답을 주었고 콘텐츠 타입이 JSON인 경우에만 처리
        if flow.response and flow.response.status_code == 200:
            if "application/json" in flow.response.headers.get("content-type", ""):
                try:
                    # 응답 바디를 UTF-8 문자열로 디코딩 후 JSON 객체로 로드
                    data = json.loads(flow.response.text)
                    
                    # 3. JSON 구조 내에서 바꾸고자 하는 키값 변조 (예시)
                    # 실제 앱이 사용하는 JSON 구조(예: {"title": "공지사항", "content": "내용"})에 맞게 수정
                    if "title" in data:
                        data["title"] = "[화이트해커 실습] 변조된 공지사항"
                    if "content" in data:
                        data["content"] = "Mitmproxy를 이용해 로컬 프록시 단에서 데이터를 조작하였습니다."
                        
                    # 4. 변조된 데이터를 다시 JSON 문자열로 변환하여 덮어쓰기
                    flow.response.text = json.dumps(data)
                    print(f"🎉 [MitmAddon] {flow.request.path} 데이터 변조 성공!")
                    
                except Exception as e:
                    print(f"❌ [MitmAddon] 에러 발생: {e}")
```

#### 2단계: 스크립트와 함께 mitmproxy 구동
작성한 파이썬 스크립트를 로드하여 프록시를 켭니다:
```bash
mitmweb -s docs/mitm_addon.py
```
이 상태로 스마트폰 앱에서 해당 API를 호출하면, 서버에서 내려온 응답 데이터가 PC에서 실시간으로 필터링되어 가짜 내용으로 바뀐 채 스마트폰 앱으로 유입됩니다. 스마트폰 화면에 조작된 공지사항 텍스트가 렌더링되는 모습을 직접 확인할 수 있습니다!
